# _BRAND_SYSTEM: reusable Remotion motion-design system

This project holds the "Paper Workshop" identity: premium paper diorama, editorial cut-out motion graphics and authentic real-world media.

The identity does not depend on a mascot. It comes from palette, typography, textures, the motion language, composition, physical metaphors and sound. The research is in `../00_VISUAL_IDENTITY_RESEARCH/`.

- **Stack:** Remotion **4.0.537** (Free License: individual creator, or a company with up to 3 employees), React 18.3.1 and TypeScript 5.6.
- **Machine profile:** 8 GB RAM, so `remotion.config.ts` sets concurrency to 1 and output to JPEG frames encoded as H.264 at CRF 16.

## Layout
```
src/
  brand/                     ← shared, episode-independent
    tokens.ts                palette (signature yellow = productive capacity), fonts, safe zones, shadows
    fonts.ts                 local OFL fonts (Alexandria, Baloo Bhaijaan 2, Lalezar, IBM Plex Sans Arabic, JetBrains Mono)
    anim.ts                  easing, springs (pop/slam), keyframes, seeded random, paper "boil", camera shake
    timing.ts                narration-driven timeline (word → frame), automatic phrase chunking for captions
    paper.tsx                Paper sheets (hand-cut edges, fibre texture, contact shadow), Backdrop (+patterns, floor), PaperGrade (grain, boil, vignette)
    type.tsx                 PaperWord, CaptionTrack (RTL word strips), TitleCard (index card + clip), HeroWord (2-layer cut type), Badge, Label
    media.tsx                PhotoPrint / FootagePrint (taped prints, Ken Burns, credits), PaperScreen (TV / monitor window), Credit
    props.tsx                SVG paper props: RobotArm (+armTip), Factory, Car, Truck, House, Furnace, Excavator, Conveyor, Press, SolarPanel,
                             WindTurbine, Pylon, Bolt, Chip, Bank, Balance, Banknote (fictional), Crate, Ingot, Ore, Icon set, FlowPath, Sparks, CutText
    diagram.tsx              PaperCounter (odometer tiles), Camera, Stage (SVG 1080×1920), PaperWipe
    scenes/IndustrialWorld   pop-up industrial landscape (basic/full, robots, flows, collapse)
  episodes/no-money/         ← episode-specific
    data/words.json          verified word timings of the original narration
    ep.ts                    timeline, scene ranges, caption chunks, emphasis words
    scenes/*.tsx             A Hook … M Finale
    NoMoneyAnymore.tsx       master composition (scenes + captions + paper grade)

  make_textures.py           regenerates the paper textures

```

## Making a new episode
1. Put the narration in the episode folder and transcribe it with word timestamps. The Whisper scripts are in `../03_NO_MONEY_ANYMORE/02_TIMING/`.
2. Copy `words.json` into `src/episodes/<slug>/data/`.
3. Write `ep.ts`, which defines scene ranges as word anchors.
4. Build each scene from `brand/` parts. Anchor every event to `wf(wordIndex)`.
5. Register the composition in `src/Root.tsx`.
6. Use `npm run studio` to preview and `tools/stills.sh` for QC stills.

## Rendering (what was used for episode 03)
```bash
npx tsc --noEmit                                             # typecheck
npx remotion bundle src/index.ts --out-dir=out/bundle        # bundle once
npx remotion render out/bundle NoMoneyAnymore out/chunks/c01.mp4 --frames=0-199 --muted --concurrency=1
# … the remaining chunks (≈2 min per 300 frames on this PC), then:
ffmpeg -f concat -safe 0 -i out/chunks/list.txt -c copy out/chunks/picture.mp4
# final encode + mux of the separately produced mix (see ../03_NO_MONEY_ANYMORE/README.md)
```
The video is rendered muted. The narration, music and effects are mixed in Python, in `../03_NO_MONEY_ANYMORE/04_SFX_MUSIC/audio_design.py`, using the same word anchors. Re-render only the chunks that changed.

## Identity rules (short)
- **Yellow `#F2B630`** marks productive capacity: robots, energy, output and the hero word. Do not use yellow backgrounds.
- **Real media is evidence.** Show it as a taped print or footage window with a credit tag. Illustrations explain. Hypothetical or speculative claims carry a badge.
- **Cuts** fall on phrase onsets. One main mover at a time. Every motion has a visible cause.
- **Arabic first:** RTL word strips with no letter-spacing, the narrator's dialect kept, and Western digits on counters.
