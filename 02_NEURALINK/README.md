# NEURALINK — The Future of the Human Mind (Arabic Instagram Reel)

The final video is `08_RENDERS/NEURALINK_FINAL_CINEMATIC.mp4`: 1080×1920, 30 fps, H.264 + AAC.
The edit is built entirely around the original voice-over in `01_AUDIO/Original/`, which is never modified.

## Folders
| Folder | Contents |
|---|---|
| `01_AUDIO/Original/` | Master voice-over `NeuralLink chip vid 2.m4a.mp4` (read-only copy; SHA-256 `EBE79AD1…1C44FCE`). The file the user supplied sits unchanged in `01_AUDIO/`. |
| `02_REFERENCES/` | Empty. No style references were supplied, so the brief's written direction was used. |

| `05_3D_AND_GRAPHICS/` | `blender/` (scene builders + .blend files), `renders/A,B,C,D/` (3D PNG sequences), `source_models/` (BodyParts3D), `fonts/` |
| `06_MUSIC_AND_SFX/` | `music_stem.wav`, `sfx_stem.wav` — original, synthesised by `audio_design.py`. |
| `07_PROJECT/` | The editable project: `scripts/`, `timing/`, `audio/final_mix.wav`, `media_sources.json`, the Python venv and tools. |
| `08_RENDERS/` | The final MP4 and previews. |

## How the edit is defined
- `07_PROJECT/scripts/nl/timeline.py`
  - `SCENES`: the edit decision list, as start and end times on the voice-over.
  - `SUBS`: subtitle chunks timed to the measured words, plus the words to highlight.
- `07_PROJECT/scripts/nl/scenes.py`
  - One function per scene, holding all the art direction: framing, motion, typography and labels.
  - `BADGE`: the real / simulation / future label for each scene.
  - `CREDIT`: the on-screen credit line for each scene.
  - `TRANS`: the transition into each scene.
- `07_PROJECT/scripts/nl/gfx.py`
  - The design system: palette, Arabic typography (Pillow + raqm shaping, then skia), print and photo drawing, colour grades.
- `07_PROJECT/timing/`: the Whisper word timings and the corrected-region passes the edit is locked to.

## Re-rendering
Run everything from `07_PROJECT` with `PYTHONUTF8=1`, and render one heavy process at a time (this PC has 8 GB of RAM).

```bash
# 1) 3D shots (Blender 4.2 LTS portable, in tools/), only if you changed the 3D:
blender -b --factory-startup -P ../05_3D_AND_GRAPHICS/blender/build_anatomy.py       # rebuild anatomy.blend
bash ../05_3D_AND_GRAPHICS/blender/render_all.sh 80 A B D                              # shots A B D at 80 %
blender -b --factory-startup -P ../05_3D_AND_GRAPHICS/blender/build_neurons.py -- ../05_3D_AND_GRAPHICS/renders/C 80 1 60
# 2) audio (score + SFX + final mix; the voice gets only one scalar master gain):
.venv/Scripts/python.exe scripts/audio_design.py
# 3) picture (about 2,136 frames, single process):
.venv/Scripts/python.exe scripts/render.py video ../08_RENDERS/picture_only.mp4
# 4) mux (audio stays at 44.1 kHz, so the voice is not resampled):
.venv/bin/ffmpeg.exe -i ../08_RENDERS/picture_only.mp4 -i audio/final_mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -movflags +faststart ../08_RENDERS/NEURALINK_FINAL_CINEMATIC.mp4
```

Quick checks:
- `render.py stills <dir> 12.5 30.0 …` renders single frames at given times.
- `render.py video out.mp4 f0 f1` renders a frame range.
