# V3 storyboard: «المصاري رح يبطل إلها قيمة» (No Money Anymore)

This is a full visual re-direction on the **locked V1 soundtrack**.

**Timing source:** the timeline uses the verified word timings (`_BRAND_SYSTEM/src/episodes/no-money/data/words.json`). Each new visual event is placed on a sound cue that already exists in the V1 mix (`../04_SFX_MUSIC/audio_design.py`, cue sheet). Cue frames are cue seconds × 30.

**Identity:** palette, paper textures, contact shadows, fonts (Alexandria, Baloo Bhaijaan 2, Lalezar), caption strips, taped real-media prints with credit tags and hypothesis badges are all unchanged.

**Redesign types:** **R** = completely replaced (new concept and composition), **S** = substantially redesigned, **K** = kept from V1 (evaluated as strong).
